## JSON字段说明

`officialCoursework.json` 是10项记录的数组：HCI 1项、CGR最终+3个检查点、MLP 2个秋季+2个春季节点、AML 1项待确认。

- `deadline`为ISO日期；null表示未在核对材料中确认。
- `deadlineLabel`保留原文可确认的时间与缺失情况。
- `source`包含绝对路径与页码；`sourcePath`、`sourcePage`便于后续建立原件入口。
- `requirementsKind`区分详细brief概括、导论高层概括与核对下一步；AML核对事项不是官方任务清单。
- `weight`只填写材料明确的课程评估百分比；feedback-only不擅自填0%。
- `status`陈述证据范围，不代表学生完成或提交状态。
- `semester`供秋季/春季分开展示，不能代替学校学期日历。

原文件均可只读本地打开，不需要上传至模型或外部服务。正式平台如有更新通知、新版brief或个别安排，需学生重新确认；本记录不覆盖后续改期或特殊情况。
