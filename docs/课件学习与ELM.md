# 逐份课件学习与 ELM

更新：2026-10-14。

## 使用流程

1. 首页点击课程卡，进入该课程资料空间。
2. 选择原有课件，或上传 PDF / PPTX / DOCX / TXT / Markdown，点击“开始学习”。
3. 本机解析文字，默认形成最多 5 节阅读路线。三页以上通常分 3–5 节；短文件按实际页数减少。扫描页和图片公式尚未做 OCR。
4. 展开“学习路线来源”，点击“ELM 生成学习路线”，根据当前文件片段生成中文知识点、阅读步骤与四选一理解题。失败时保留此前路线；成功切换路线会重置该文件的模块进度。
5. 在“知识问答”中提问。配置可用时默认选择 ELM 辅导，只有点击发送才发起模型请求；可随时切换本机检索。来源按钮可定位“原文页”。
6. 正确完成本节检查后继续下一节；进度自动保存，不需要一次完成整份文件。

## 内容来源

每份文件的学习路线、题目、原文与进度独立保存，不合并其他课程。原有四门课程另附中文基础概念讲解和原创示例，来源页码已经人工对照；新上传文件不会套用这些固定内容。本机问题只定位原文与核对来源，不冒充模型语义出题。

问答先检索当前文件，模型仅收到最多四个相关片段。没有文字命中时明确说明来源不足，不调用模型。学习路线使用各页有限长度的片段，保留完整页序覆盖，但这不表示所有图示或每一个概念都已经被模型理解。课件文本作为资料处理，不执行资料中的命令。

## 学校接口与配置

当前电脑复用此前的学校 ELM 服务端配置，所选模型是账户实际返回的 `Qwen/Qwen3.5-397B-A17B-FP8`。项目 `.env.local` 只保存现有配置文件路径、模型名和解析运行时路径，未把原始密钥复制进项目。凭据由 Node 后端读入内存，浏览器只接收服务是否可用和模型名。

接口为 OpenAI 兼容的 `chat/completions`。ELM 输出在服务端检查结构、选项索引和现有页码；引用格式通过不能证明解释或题目事实完全正确。回答中的文本公式会用 KaTeX 排版；以原课件核对，尤其是图片公式、评估作业和模型未覆盖的长页内容。

迁移到组员电脑时复制 `.env.example` 为 `.env.local` 并填写本人配置，安装 Python 的 `pypdf`；读取 YAML 时还需 PyYAML。详见 [后端接口](../server/README.md)。不要把密钥发到聊天，也不要提交 `.env.local`。

## 保存与运行

新文档和答题进度存于 `student-workbench-study` IndexedDB；原文件仍存于原附件数据库。删除上传文件时同时移除该课程该文件所有版本的浏览器学习缓存与进度。后端解析文档仅有有限的内存缓存，重启清空；临时上传文件解析后清理。浏览器清除站点数据会移除本地资料，尚无账号或云端同步。

需运行 `npm run dev -- --port 5175` 或 Vite preview 才有解析与 ELM 接口；单独打开构建 HTML 不具备这些服务。当前服务器只监听本机，未公开发布。
