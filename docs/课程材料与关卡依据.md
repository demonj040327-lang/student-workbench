## 3. 复习计划与完整课程的区别

每门课程有三个基础模块与三个短关卡，并配四个可拆开的课后复习步骤。计划中的笔记、草图、公式标记与用时是 Demo 建议，学生可以修改。它们不要求实际招募 HCI 参与者，不输出课程作业代码，不将复习完成标为官方 coursework 完成。

演示计划的目标完成日期由界面安排，必须标为个人演示安排，不是课程真正截止日。课件页码是证据入口，不代表已经覆盖所有考试内容或官方学习目标。全部题目完成只说明完成本轮基础检查，不能自动显示“已经掌握整门课程”。

## 4. 数据与本地预览约定

内容位于 `src/courseContent.ts`，导出 `courses`、`questions`、`coursePlans` 与 `courseMaterials`。每题有 `sourceId`、`sourcePage`；对应材料保留原始绝对路径和仅本地预览 URL。

| 材料 ID | 本地 URL | 原件性质 |
|---|---|---|
| `hci-lecture` | `/course-materials/hci-week-2.pdf` | 原 PDF |

原文件仅用于用户本地 Demo 预览；不上传到模型服务、不公开课件、不跟随外部部署。若主实现将文件放入本地 `public/course-materials/`，应将该目录加入版本控制与公开构建排除规则。内容模块本身只保存来源与人工概括；打开/页码跳转是否可用由主实现测试。PDF 阅读器对 `#page=` 的支持可能不同，应同时显示页码并允许手动查找。

## 5. 仍需验收

确认每个 `sourceId` 能找到对应文件、每个 `sourcePage` 在文件范围内；逐题点击出处，检查链接与显示页码；手机打开 PDF 与 PPTX 下载路径分别验证；测试课程切换后题目、资料与计划仍属于正确课程。后续如接模型出题，应重新进行来源与题目有效性审核，不能因为这批预设题已核对就宣称自动生成质量可靠。
