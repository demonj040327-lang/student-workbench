# 课堂录音、转写与译文讲解

功能位于学生端。功能位于学生端，录音与文字属于学生本机记录，不发布给教师或全班。

## 入口与布局

学生端顶部有“课堂录音”按钮，可在课程页面和专用课件阅读页打开。

- 电脑：右侧面板。打开后，课件区域自动让出宽度；阅读页暂时收起原有问答列，关闭录音面板后恢复。
- 手机：底部面板。收起后可继续看课件，顶部图标和计时显示录音状态。
- 面板非模态，不阻止翻页或操作其他页面。按面板内 Escape 可收起；收起不结束录音。
- 录音绑定开始时选择的课程。录制中切换页面不会重新归类；若打开其他课程，会提示当前录音仍属于原课程。

## 一次课堂的使用流程

1. 打开课程或课件，点击顶部“课堂录音”。确认课程，点击“开始新录音”。电脑端默认采集视频／电脑声音：在浏览器弹窗中选择播放录播的标签页，并勾选“分享标签页音频”。现场上课可展开“音频设置”改用麦克风；不支持共享音频的浏览器默认使用麦克风。
2. 默认开启“实时英文转写（本机）”。当前识别器是 `small.en`，不是中文识别器。无需购买语音识别 API；需本机语音服务运行。
3. 一边看课件，一边看“原文”。可以随时修改识别文字；新字幕追加，不覆盖人工修改，光标位置和正在阅读的滚动位置会尽量保留。临时识别内容与确认文字分开显示。
4. 要实时翻译，开始前连接自己的 DeepSeek 或 ELM API，并勾选“实时翻译”。它只发送确认文字，不上传音频，也不回退使用教师凭据。请确认输出语言；新录音的默认语言跟随当前界面。
5. “译文”可以手工修正。新翻译追加到后面，不清空已有修改。翻译接口失败会暂停翻译并提示，录音与原文转写继续。
6. 点击“结束并保存”，等待最后的文字和音频处理完成。现在可以回听、拖动播放位置、下载整条录音、导出原文/译文/讲解。
7. 停止后检查译文，点击“确认译文并生成讲解”。模型使用当前编辑后的译文，不会偷偷改用最初识别稿。译文再次修改后，旧讲解显示待更新提示。
8. 本课程历史录音可在面板中选择；标题可修改，删除操作放在折叠的“删除这条录音”中，需要点击明确的确认按钮。

## 连续录音与文字处理

一次录制保存为一个可回听、可下载的音频文件，不随课件翻页切段。内部按约 100ms 发送 PCM 音频、约 2 秒写入压缩音频和文字检查点，属于传输与保存机制，不是用户可见的课件分段。

实时翻译把新增的确认文字逐步发送给个人模型，显示为一份连续译文；不会为了实时显示而反复重译整节课。原文发生与已翻译内容冲突的修订时，自动翻译会暂停并提示校对；手工改稿不会被后台覆盖。结束后也可显式重新翻译当前原文，该操作替换译文。

课程讲解以确认后的完整译文作为一次输入。当前上限为 100,000 字符；一次重新翻译原文上限为 12,000 字符。达到限制或模型返回截断内容时会报错，不静默截短或保存不完整讲解。较长课程可继续实时翻译，不受单次重新翻译的长度限制；自动转写文稿超过此长度时仍会保留；超过 100,000 字符的译文须先整理，才能一次生成讲解。

## 保存与恢复

录音元数据、原文、译文、讲解和音频块保存在当前浏览器 IndexedDB 中，演示与正式工作区分别标记。原文与译文自动保存；录音仍在进行时会定期保存已收到的内容。

- 刷新会中断现场录音，页面会先显示浏览器离开提醒。重新打开后，可以找到中断记录和已保存音频；不自动重新开启麦克风。
- 不承诺浏览器崩溃时最后几秒一定完整，遇到存储空间不足会提示立即下载；清除站点数据会删除本机录音。
- Key 只存在当前页面内存，刷新后需重新填写，不写入录音或浏览器持久存储。
- 统一使用同一个访问地址。`localhost:5175`、`127.0.0.1:5175` 和其他端口的浏览器存储互不相通。

## 启动

本机已安装的环境可以从项目根目录执行：

```sh
npm run dev:classroom
```

该命令启动课程网站，复用或启动 `127.0.0.1:8000` 的语音服务。启动器只结束自己启动的语音进程，不关闭原先独立运行的服务。首次模型加载完成前，转写暂不可连接。

也可以分两个终端运行：

```sh
tools/start-local-speech.sh
```

```sh
npm run dev -- --port 5175 --strictPort
```

其他电脑的模型安装参见 [本机语音服务安装](LOCAL_SPEECH_SETUP.md)。集成模式语音端口固定为 8000，通过 Vite 同源 WebSocket 转发；未启动服务时，可以取消实时转写，仅录制音频。

## 当前边界

电脑端默认使用视频／电脑音频，无需先切换来源。浏览器仍强制要求每次确认共享来源，网页不能静默监听系统声音。优先在 Chrome 或 Edge 中打开录播，开始后选择视频标签页并勾选共享音频，即使戴耳机也可采集。是否提供窗口／整个屏幕的系统声音由浏览器与系统决定；不提供时，请把视频放在浏览器标签页播放。

共享需要同时请求画面权限，但画面不会录制、保存或发送给转写服务，只使用音频轨道。停止浏览器共享会结束并保存当前录音；取消授权、忘记共享音频时会明确提示，不会悄悄改录麦克风。手机等不支持共享音频的环境继续提供麦克风模式。手机锁屏、后台录音、真实长课堂、多设备同步尚未作为生产能力验收。

实现依据：[Chrome 共享音频控制](https://developer.chrome.com/docs/web-platform/screen-sharing-controls)、[MDN getDisplayMedia 授权要求](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia)。

该功能是学习辅助：讲解来自课堂译文，明确标记为 AI 整理，不是教师原话或已核实的课程标准。
