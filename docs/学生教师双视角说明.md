# Workbench 使用说明

## 启动与进入

安装和启动见 [项目首页](../README.md#run-locally)。打开 `http://localhost:5175/`，选择教师或学生以及界面语言。示例入口使用 `?demo=1&role=teacher` 或 `?demo=1&role=student`，演示与个人工作区的数据分开。

完整英文操作步骤见 [User guide](USER_GUIDE.md)。本页提供中文快速操作。

## 教师

1. 在教学总览创建课程，进入“课程与课件”选择课程；可修改课程信息或删除课程。
2. 选择“课程课件”，填写标题、周次及可选主题，上传 PDF、PPTX、DOCX、TXT 或 Markdown，普通上传每份不超过 25 MB。
3. 按需选择“保存原文草稿”“AI 生成草稿”或“AI 生成题目”。指导和题目可分别生成，已有指导后也可补题。生成使用页面内后台任务，可继续上传或切换页面；刷新和关闭会中断未完成任务。
4. 在“检查与编辑”中修改讲解、题目与答案，核对原文，使用学生预览，再发布给学生。可先发布原文；修改或重新生成后需检查并再次发布，也可以撤回。
5. 上传作业时切换到同级的 Coursework 按钮，上传作业说明，让 AI 起草介绍并提取起止日期。核对出处、按 UTC 确认日期后发布。评分标准解释与个人步骤由学生按需生成。列表中可检查编辑、重新生成或撤回。
6. 在课程讨论回复学生，使用待回复提醒定位问题；学生反馈展示已有查看和练习参与记录，不代表掌握程度。

教师使用独立配置的教学 ELM，配置见 [API 设置](../server/README.md)。

## 学生

1. 学期总览展示经过时间、各课程作业起止与个人进度，可添加关联课程或其他活动的个人安排。“学期已过”和“完成比例”是不同指标。
2. 每周任务按课程展示，可切换周次与勾选步骤。提醒仅在平台内显示，不提供关闭页面后的系统推送。
3. 在“我的课程”选课，再按周展开。学习与 Coursework 为同级按钮。教师未设置主题时，仍可按周找资料。
4. 打开课件进入独立阅读页面，滚动 PDF 查看当前页，拖动分隔调整阅读区与问答区宽度，使用私人笔记、分步指导及原文引用。
5. 选择题提交后查看解释及出处。教师已发布的练习不需要学生个人 API；模块勾选与答题记录不等同于知识认证。
6. 打开作业，阅读原说明，按需生成个人步骤、理解提交要求和评分标准或进行问答。手动记录“已在学校系统提交”不会真实提交文件。

## 个人 API 与原文问答

在“我的 AI API”选择 ELM 或 DeepSeek，填写本人 Key 与账户可用模型。刷新会清除 Key；选择完成不表示已验证额度。学生调用不回退使用教师凭据。

在当前课件的问答框输入问题，阅读引用并回到原文核查。“解释本页”使用当前页上下文。检索针对选中资料，依据不足的问题可能无法解答。没有 API 时可使用“只检索原文”，返回摘录而非新的 AI 解释。

模型操作会将相关文字发送给选定提供方，可能产生费用。扫描图片、图示和图片公式可能未覆盖，应核对原文。

## 课堂录音与文字编辑

操作见 [课堂录音与翻译](课堂录音与翻译使用说明.md)，首次配置见 [语音服务安装](LOCAL_SPEECH_SETUP.md)。

学生打开课程或课件后点击顶部“课堂录音”，确认课程。电脑端默认共享录播声音，浏览器弹窗中选播放视频的标签页并勾选共享音频；现场课堂可以改用麦克风。浏览器及系统决定能否共享系统声音。

本机服务提供英文转写，可编辑原文；连接个人 API 后按所选语言翻译，可编辑译文并基于确认后的文本生成讲解。结束后可回听、下载和导出。收起面板或翻页不主动结束录音，也不会自动将话语对齐到课件页码。

## 学习搭档与课程讨论

在学习搭档中选择可以帮助或希望学习的课程，设置语言和可用时段后保存。匹配按课程进行，不强制选择知识点。发送邀请、对方接受后可交流，也可以暂停匹配。示例身份为虚构人物，本机身份不是学校认证。

需要教师解答时，在对应课程讨论区提问并查看回复。

## 保存与常见问题

- 课程、草稿、进度主要使用浏览器存储；课程与同伴服务也有本地服务数据。未提供完整的学校账户权限与可靠跨设备同步。
- 统一使用同一访问地址。`localhost:5175` 与 `127.0.0.1:5175` 属于不同浏览器来源。
- 学生看不到资料：确认课程、工作区与发布状态。草稿不会显示给学生。
- 模型失败：检查提供方、Key、模型和额度，可先用原文检索。
- 解析不到文字：优先使用含可选择文字的文件；当前不自动识别所有扫描或图像内容。
- 录音无声音：检查共享音频选项、麦克风权限或本机识别服务。不能自动捕获所有应用声音。
- 手机适配是网页布局支持，不代表已发布原生 App。录音须遵守教师与学校规定。
