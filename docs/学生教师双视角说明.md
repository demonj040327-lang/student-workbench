# workbench 使用说明

适用版本：学生与教师双视角本地原型  
更新日期：2026 年 10 月 22 日

workbench 将课程资料、作业进度与课件学习放在同一个工作区。教师负责准备和发布课程内容，学生直接使用已发布资料学习，并使用自己的 ELM API 进行课件问答。

## 1. 进入平台

| 入口 | 地址 | 用途 |
|---|---|---|
| 学生演示 | [打开学生演示](http://localhost:5175/?demo=1&role=student) | 查看示例作业、时间轴、学习模块和练习 |
| 教师演示 | [打开教师演示](http://localhost:5175/?demo=1&role=teacher) | 体验上传、生成、编辑和发布 |
| 正式教师工作区 | [打开教师工作区](http://localhost:5175/?role=teacher) | 创建自己的课程并上传真实资料 |
| 正式学生工作区 | [打开学生工作区](http://localhost:5175/?role=student) | 使用正式工作区中已经发布的课程内容 |

右上角“学生 / 教师”切换视角，“中文 / EN”切换界面语言。手机通过底部导航进入首页、课程及每周任务；电脑使用左侧导航。

演示和正式工作区的数据分别保存。在演示中上传的资料不会进入正式工作区。首次使用正式工作区时，请先切换到教师视角创建课程。

## 2. 教师：准备和发布课程内容

### 2.1 创建课程

1. 切换到“教师”视角，在“教学总览”点击“创建课程”。
2. 填写课程名称、课程简称和授课教师，可补充课程简介并选择课程颜色。
3. 点击“创建课程”，进入该课程的资料页面。

教师页面展示分配给当前演示教师的课程。内置示例教师 Alex Morgan 负责 HCI 和 POL；学生示例中还包含其他教师的课程。

### 2.2 上传课件

1. 进入“课程与课件”，选择对应课程。
2. 在“上传本周课件”中选择课程周次，可填写课件标题；留空时使用文件名。
3. 拖入文件，或点击“选择文件”。目前支持 PDF、PPTX、DOCX、TXT 和 Markdown，每份不超过 25 MB。
4. 等待解析完成，文件会出现在下方列表，状态为“草稿”。

此时仅提取了课件文字，学生还看不到这份资料。扫描件或图片中的文字、公式可能无法提取，请尽量使用含可选中文字的文件。

### 2.3 生成并检查指导与练习

1. 在课件列表点击“生成指导与练习”。
2. 系统使用教学 ELM 接口，根据课件起草学习模块、概念讲解、知识点、阅读步骤及选择题。通常分成 3–5 个模块，短文件可以更少。
3. 生成完成后进入编辑窗口，核对模块内容、题目、选项、正确答案与解释；通过“核对原文”查看依据。
4. 修改后点击“保存为草稿”。后续也可通过“检查与编辑”再次调整。

教学接口可以使用本机已有配置，或在教师视角的“教学 ELM API”中填写自己的 Key 和模型名称。生成失败时会显示错误原因，不会将原文检索冒充 AI 指导。用于生成的课件文字总量不超过 60,000 个字符，较长资料请按章节拆分。

### 2.4 发布给学生

检查完成后，回到课件列表，点击“发布给学生”。状态变为“已发布”，学生可以在对应课程中打开资料。

- 点击“撤回发布”，资料会重新成为草稿，学生页面不再展示。
- 编辑后保存，或点击“重新生成草稿”，会使资料回到草稿状态，需要再次发布。
- 尚未生成指导时，也可以先发布原文；学生仍可阅读资料和提问，指导与练习会显示暂无内容。

### 2.5 发布作业

1. 进入“课程作业”，点击“发布作业”。
2. 选择课程，填写作业标题、开始日期、截止日期和作业要求。
3. 填写作业步骤，每行一步，然后点击“发布给学生”。

作业会进入学生的时间轴与提醒。开始日期不能晚于截止日期。学生勾选完成情况会更新自己的进度记录，不会改写教师公布的作业要求。

## 3. 学生：安排学习和跟踪进度

### 3.1 查看学期和作业

打开“学期总览”可以看到：

- **学期时间已过**：学期开始至今经过的比例，显示八位小数并实时更新。
- **作业时间轴**：按课程分组，横轴从九月延伸到次年一月；彩条表示作业的计划起止日期，深色填充表示个人完成比例。
- **本周学习安排和提醒**：查看当前周的步骤，以及即将截止或已经逾期的未完成作业。

点击作业名称或时间条，进入“作业进度”，勾选已完成的步骤。百分比随之更新，刷新页面后保留。“学期时间已过”和“作业完成比例”是不同指标，完成比例也不代表成绩或知识掌握程度。

### 3.2 使用每周任务和提醒

进入“每周任务”，按课程查看本周安排。使用左右箭头切换周次，“回到本周”返回当前周。

当前步骤按作业起止日期均匀安排，作为个人推进参考。可以随时勾选完成情况。点击顶部铃铛查看提醒，也可将提醒标为已读。提醒目前仅在平台内显示，关闭页面后不会发送系统推送。

### 3.3 阅读分步指导

1. 进入“我的课程”，选择课程和一份已发布课件。
2. 打开“分步指导”，按模块阅读概念讲解、知识点与阅读步骤。
3. 点击页码按钮，可回到“原文资料”核对。
4. 完成后勾选“我已完成这个模块”，再进入下一个模块。

学生无需重复上传教师课件。模块完成记录用于保存学习进度，不表示系统已经判断你掌握了内容。

### 3.4 完成课后练习

进入课件的“课后练习”，选择一个答案，再点击“检查答案”。提交后会显示解释及出处页码；需要复习时可点击“查看第 N 页”，也可选择“重新作答”。

已有指导和练习来自教师发布的内容，阅读与作答不需要学生自行调用 API。

### 3.5 针对课件提问

1. 在课件页面选择“课件问答”。
2. 连接个人 ELM API：电脑可点击左下角“我的 ELM API”，手机可点击右上角钥匙图标；问答页也有“管理个人 API”入口。
3. 填写“ELM API Key”和学校接口支持的“模型名称”，点击“用于本次打开”。
4. 返回问答页，输入具体问题，点击“发送问题”。
5. 阅读讲解，点击回答下方的页码核对原文。

可以问“这里的两个概念有什么区别？”“请用另一个例子解释这个定义”，也可以使用课件中的具体术语。系统只检索当前选中的课件；课件无法支持的问题，会提示依据不足。

没有个人 API 时，可以勾选“只检索原文”，再输入问题或术语。此方式返回相关原文摘录，不生成新的 AI 讲解。

## 4. API、语言与资料保存

| 项目 | 当前方式 |
|---|---|
| 教师生成指导与练习 | 使用教师填写的 Key，或本机配置的教学接口 |
| 学生 AI 问答 | 使用学生自己的 Key，不自动回退到教师接口 |
| API Key | 仅保留在当前页面内存中，刷新后需要重新填写；保存设置不等于已验证密钥有效 |
| 课程、课件与进度 | 保存在当前浏览器中，刷新后保留；清除站点数据会删除记录 |
| 中英切换 | 界面语言选择会保留；上传原文、自定义课程名和已有内容不会自动翻译 |

同一个浏览器、同一个地址的不同标签页可以同步课件发布状态。请统一使用 `localhost:5175`，避免与 `127.0.0.1:5175` 混用，两者的浏览器数据分别保存。

## 5. 常见问题

**学生页面没有课程或课件。**  
先确认是否进入了正确的演示或正式工作区。正式工作区需要由教师创建课程并发布课件；仅上传或保存草稿不会出现在学生页面。

**之前能看到的课件消失了。**  
请在教师视角检查发布状态。撤回、编辑保存或重新生成后，需要再次点击“发布给学生”。

**AI 问答提示未配置或调用失败。**  
在学生视角重新填写个人 Key，核对模型名称、接口权限与额度。刷新页面会清除 Key。也可先使用“只检索原文”。

**解析后没有文字，或某些公式没有出现在解释中。**  
请下载原课件核对。扫描图片、图示和图片公式可能未被文字解析覆盖，可换用含文本的版本。

**更换电脑或浏览器后找不到进度。**  
当前是本地原型，尚未接入学校账号和跨设备同步。现有视角切换用于演示，不等同于正式的账号权限；手机网页布局已支持，原生 App 尚未打包。
