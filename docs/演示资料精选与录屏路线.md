## 恢复或换选资料

编辑 `config/demo-library.json`：`mode` 为 `curated` 时按课程和文件名精选；改为 `all` 后刷新演示页面可重新导入完整资料库。该文件不包含原文、Key 或学生答案。不要删除本机 `data/local-demo-library`，否则原件链接和恢复入口会失效。

此次没有重新调用模型、重新上传课程原件或改写原作业日期。HCI、CGR 作业因为日期或时区未完整确认，继续作为教师草稿；不会自动展示为学生已发布作业。

## 建议录屏路线（约 3–4 分钟）

1. 教师视角：四门课程 → HCI → 第 5 周 → 检查预先生成的草稿和练习 → 修改一处内容 → 学生预览 → 发布。需要展示上传时用同一份小型原件，标清等待与预先生成结果。
2. Coursework：切到作业布置，打开 HCI 真实说明，核对介绍与原文。教师根据实际安排确认开始时间、截止时刻和时区后发布；没有确认就保留草稿，不为了画面填造学校要求。
3. 学生视角：学期总览 → 查看已经发布的作业与进度 → HCI 课程 → 折叠切换第 3/5 周 → 打开第 5 周专用阅读页。
4. 滚到第 4 页，观察页码同步；拖动栏目比例；输入“这页讲了什么”。勾选“只检索原文”展示来源检索；若要展示 AI 讲解，先配置自己的真实 API，明确这两种模式不同。
5. 切到分步指导，完成一道选择题，再回原文核对出处。私人笔记只需展示一条。
6. 学习搭档：分别选择愿意讲解和希望学习的课程 → 载入明确标注的演示搭档 → A 邀请 → 切 B 接受 → 双方交流具体问题。重点说明匹配只要求同课程，知识点由双方商量。
7. 时间允许时展示学生提问、教师待回复提醒；反馈中的本机浏览器人数不能说成真实全班统计。

## 录屏前准备

- 统一使用 `http://localhost:5175`，不要在 `127.0.0.1` 与 `localhost` 之间切换，浏览器存储按地址隔离。
- 学生与教师切换通过退出并重新选择身份；刷新会清除当前输入的个人 API Key。
- 发布真实作业后才能展示相应学生作业和时间轴；未确认日期的作业不应冒充已布置。
- 如仅需要排练虚构作业，可使用学生端已有的“载入作业流程示例（非真实作业）”，保留其示例声明。
- 先测试音量、画面比例和原文载入。视频记录本机原型，不把 localhost 当成评委可访问的线上链接。
