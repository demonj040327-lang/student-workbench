# Student Workbench · 学生学习工作台

TeachAthon 2026 简化版演示。当前界面聚焦三个功能，手机优先，同时支持电脑浏览器。

## 启动

```sh
npm install
npm run dev -- --port 5175
```

打开终端给出的本机地址。默认入口为 http://localhost:5175/。端口被占用时以终端输出为准。双击 `student-workbench.code-workspace` 可在 VS Code 编辑。

## 三个功能

| 页面 | 可实际操作的内容 |
|---|---|
| 任务总览 | 显示实时学期百分比、九月至次年一月的作业时间轴、按课程划分的本周任务；查看全部作业，勾选步骤并更新完成率；修改截止日期和学期设置。 |
| 作业拆解 | 选择课程，直接上传课件或作业说明；自动提取文字并由学校 ELM 生成 3–5 个步骤，带对应原文页序。课件生成复习行动，作业说明生成执行步骤；标题自动填写，截止日期可选。支持展开编辑、手动输入和示例草稿。 |
| 课件问答 | 选择已有课件或上传 PDF、PPTX、DOCX、TXT、MD；本机提取文字；使用 ELM 解释知识点或本地检索原文，点击依据页序核对文字并打开原文件。 |

添加课程位于右上角加号。作业百分比按已勾选步骤计算，不代表教师评分或课程掌握程度。步骤的时间只是可编辑的粗略建议。

### 建议演示流程

1. 从任务总览查看学期进度、作业截止时间和本周课程任务。
2. 打开“作业拆解”，选择所属课程，点击“选择文件并生成”，或直接拖入一份课件。支持 PDF、PPTX、DOCX、TXT、MD，最大 25 MB。上传后会自动提取文字并生成步骤，无需填写标题或粘贴内容。
3. 展开任一步骤修改内容、核对引用页序，必要时调整标题和截止日期，再加入计划。纯讲义生成复习计划，不据此编造课程作业或提交要求。
4. 在首页“全部作业”打开新作业，勾选一步，查看时间轴和完成率更新。
5. 进入“课件问答”，选 HCI 课件，询问 `semi-structured interview`，查看依据页序；可切换为本地原文检索。

示例要求为自写演示内容，不是实际课程作业。ELM 草稿的引用会核对是否存在于输入原文，上传文件还会检查引用的页序；这不等于自动验证计划的全部语义，仍需学生确认。

## 数据与服务

- 继续使用原有课程、作业和进度存储，修改前源码备份位于 `.backups/20261018-simplified-frontend/`。
- 课程与作业使用原来的 localStorage 键；课件保存在 IndexedDB。拆解草稿单独保存在当前浏览器中。
- 原来的关卡、录音、课堂记录等入口已从当前界面移除，历史数据仍保留；旧组件留存但未接入当前导航。
- 请沿用同一个访问地址，`localhost` 与 `127.0.0.1` 的浏览器数据各自独立。清除站点数据会删除本机记录。
- 课件问答只使用选中的文件；切换课程或文件会清除当前会话并取消旧请求。问答历史当前不持久保存，上传文件和解析缓存可以保留。
- 扫描图片、图示和图片中的公式不保证能被文字提取覆盖，请核对原文件。上传文件限 25 MB；拆解支持每份最多 60,000 个可提取字符，更长资料需按章节拆分。
- “选择文件并生成”会在上传后自动将提取文字发送至 ELM 生成步骤；仅提问时才将问题及相关课件片段用于问答。密钥只由本机服务端读取。
- 当前仅提供本机演示，服务绑定 `127.0.0.1`。手机布局可用设备模式查看；没有开放手机跨设备访问、账号同步或公开部署。
- 真实课件副本位于已忽略的 `public/course-materials/`，请勿将私有材料纳入公开分享包。

ELM 配置参考 `.env.example` 与 `docs/课件学习与ELM.md`，在本机 `.env.local` 设置。现有本机凭据路径继续由服务端读取，不需要把密钥填入网页。

## 当前代码入口

| 文件 | 作用 |
|---|---|
| `src/App.tsx` | 三个页面的导航、作业与课程状态 |
| `src/SemesterOverview.tsx` / `src/WeeklyCourses.tsx` | 学期时间轴、本周课程任务 |
| `src/AssignmentPlanner.tsx` | 步骤生成、编辑、草稿与保存 |
| `src/CourseQuestions.tsx` | 课件选择、上传、知识问答与原文核对 |
| `src/simplified.css` | 简化页面与手机布局 |
| `src/studyClient.ts` | 学习服务请求与上传读取 |
| `server/study-api.mjs` | 本机解析、检索、ELM 调用与步骤原文检查 |
| `references/index.html` | 组内设计参考链接与截图 |

```sh
npm run build
node --test server/study-api.test.mjs
npm run preview -- --port 5175
```

React + TypeScript + Vite。构建到 `dist/`；直接静态托管不包含学习接口，本机 dev 和 preview 会挂载后端。运行测试无需真实模型凭据，测试中的模型调用使用本机模拟响应。
