# Student Workbench · 学生学习工作台

TeachAthon 2026 本地交互 Demo。手机优先，同一套网页支持电脑；可以直接在 VS Code 编辑。

## 开始查看

在本项目目录打开终端：

```sh
npm install
npm run dev -- --port 5175
```

访问终端输出的 Local 地址，通常为 `http://localhost:5175/`。端口被占用时，Vite 会给出另一个地址；以终端为准。当前服务仅绑定电脑本机，避免向局域网共享私有课件。手机版布局可在浏览器设备模式查看。

手机真实访问需要后续配置获准的 HTTPS 服务与访问控制；录音也要求安全环境（HTTPS 或当前设备 localhost）。这次没有配置公开网址、局域网共享或跨设备账号同步。

双击 `student-workbench.code-workspace` 可在 VS Code 打开；快捷任务提供启动和构建。

## 可以实际操作

- 首页显示按真实时钟更新的学期百分比（8 位小数），九月至次年一月的横向日历图，按课程展示 coursework 计划区间和完成比例；无日期项目单列。
- 首页每周任务按课程分卡，打开课程后选择具体课件学习。
- 点击作业更新步骤、确认日期；调整学期起止日期。
- 本周查看、课程／日期筛选、15 分钟短任务筛选，切换周次。
- 创建课程，手动添加作业说明、截止日和步骤。
- 完成／恢复步骤，调整预计用时，标记卡点，顺延一天；超过截止日时提示。
- 查看四门真实课程的本地课件，每份课件自动解析并建立 3–5 节本机阅读路线；在 ELM 中生成中文讲解、理解选择题和带出处的知识问答。
- 已整理的基础概念提供中文讲解与原创例子；本机检索展示当前文件原文摘录。每份文件独立保存答题、模块进度，刷新后可继续。
- 按课程上传并保存文件、预览 PDF、下载、删除；文件存放在当前浏览器 IndexedDB。
- 按课程记录课堂疑问；用户主动开启麦克风后录音并保存，可从课程资料播放与删除。
- 刷新后保留课程、进度、疑问、文件及录音；浏览器清除站点数据会删除本地数据。

## 内容依据与边界

默认课程是 HCI、Computer Graphics Rendering、Applied Machine Learning 和 Machine Learning Practical。新首页另加入经官方材料核对的 coursework 与提交检查点；进度由你自己更新，未随意填入进度数值。详见 [学期首页说明](docs/学期首页.md)。旧的“课程复习”三关是人工核对的概念检查，见 [课程材料与关卡依据](docs/课程材料与关卡依据.md)。新的“开始学习”按当前文件实际提取文字；本机路线按页序分段，点击“ELM 生成学习路线”后才由模型生成语义讲解与理解题，二者在界面中明确区分。详见 [逐份课件学习与 ELM](docs/课件学习与ELM.md)。

旧复习计划中的预设日期是个人目标；首页 coursework 草稿的正式日期附有原材料依据，尚未核实的日期显示待确认。手动创建的作业使用用户确认的截止日期。

完成数代表已做步骤或题目，不代表整门课已掌握。已接通学校 ELM 的模型 API；本机解析及 ELM 出题与问答需要正在运行的 Node 服务。尚未实现录音转写、账号、云同步或正式学习效果测量。课堂记录保存疑问；录音只采集麦克风，不宣称直接捕获在线视频系统音频。

仅本地提供原课件副本用于本次授权演示。`public/course-materials/` 已列入 `.gitignore`，公开部署或分享打包前应去除原课件，并核对使用许可；本项目尚未公开部署。

## 项目结构

| 位置 | 用途 |
|---|---|
| `项目方案.md` | 正式参赛讨论稿、研究依据、创新点、范围与时间安排 |
| `docs/技术方案.md` | API 与后端实现路线、权限和数据边界 |
| `docs/课程材料与关卡依据.md` | 真实课程文件、题目与页码核对 |
| `src/App.tsx` / `src/styles.css` | 页面交互与响应式样式 |
| `src/courseContent.ts` / `src/courseTutorials.ts` | 四门课程的原文映射与中文概念讲解 |
| `src/SemesterOverview.tsx` / `src/WeeklyCourses.tsx` | 横向月份图、实时学期百分比、分课程周任务 |
| `src/MaterialStudy.tsx` / `src/studyStore.ts` | 逐份资料的阅读、选择题、问答与独立本地进度 |
| `server/study-api.mjs` / `server/extract_document.py` | 本机文字提取、检索、ELM 服务端调用 |
| `.env.example` | 可迁移的模型配置示例，不含真实凭据 |
| `src/data.ts` | 周计划样例与浏览器进度保存 |
| `src/storage.ts` / `src/Recorder.tsx` | 文件保存与麦克风录音 |
| `references/index.html` | 可点击查看截图与官方链接的参考图库 |
| `references/竞品与前端参考.md` | 布局拆解、证据与设计推论 |
| `references/REA证据记录.md` | 实际 REA 观测及未知事项 |

React + TypeScript + Vite。依赖精确版本记录在 `package-lock.json`，复现时可用 `npm ci`。

```sh
npm run build
npm run preview -- --port 5175
```

生产构建输出 `dist/`。直接托管这些静态文件不包含学习 API；当前 `npm run dev` 和 `npm run preview` 都挂载本机学习后端。前端参考中的图片来自官方公开页面，用于组内研究，不代表本项目原创设计资产。参考图不是竞品登录后的操作验证，也没有恢复闭源产品的完整源码。
